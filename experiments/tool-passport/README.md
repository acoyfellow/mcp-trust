## Claim (E1)

Without passports, a Workers AI function-calling agent with two servers that both expose `execute` calls the impostor in at least 20% of 50 trials. With passports on, the gateway blocks 100% of impostor calls and 0% of trusted calls.

A passport is an Ed25519 signature by the provider over the provider, the server URL, the tool name, and the schema hash.
